ИНСТРУКЦИЯ ПО РАБОТЕ С СЕРВЕРОМ (Multiplayer Slot Casino)

1. КАК ЗАПУСТИТЬ СЕРВЕР:
   - Откройте терминал (PowerShell, CMD или терминал в VS Code).
   - Перейдите в папку сервера (если вы еще не в ней):
     cd "d:\Казино\server"
   - Введите команду для запуска:
     npm start
   - Если сервер запустился успешно, вы увидите сообщение в консоли (обычно о том, что сервер слушает порт, например 3000).

2. КАК ОСТАНОВИТЬ СЕРВЕР:
   - Перейдите в окно терминала, в котором запущен сервер.
   - Нажмите комбинацию клавиш:
     Ctrl + C
   - Если терминал спросит "Завершить выполнение пакетного файла (Y/N)?", введите "Y" и нажмите Enter.

3. ПРИМЕЧАНИЯ:
   - Перед первым запуском убедитесь, что у вас установлены зависимости. Если сервер не запускается, выполните:
     npm install
   - Для работы сервера необходим установленный Node.js.
