============================================================
ИНСТРУКЦИЯ ПО ЗАПУСКУ И ОСТАНОВКЕ СЕРВЕРА КАЗИНО
============================================================

1. КАК ЗАПУСТИТЬ СЕРВЕР (Два способа)
------------------------------------------------------------

Способ А: Через готовый файл (Самый простой)
   - Просто запустите файл "RUN_CASINO.bat" в корневой папке.
   - Он сам установит нужные модули и запустит сервер.

Способ Б: Вручную через терминал (Для отладки)
   1. Откройте терминал (CMD или PowerShell).
   2. Перейдите в папку проекта:
      cd /d "d:\Казино"
   3. Перейдите в папку сервера:
      cd server
   4. Если вы запускаете сервер впервые, установите зависимости:
      npm install
   5. Запустите сервер:
      npm start
   6. После этого вы увидите сообщение о том, что сервер запущен.
   7. Откройте в браузере: http://localhost:3000 (или другой порт, указанный в консоли).

2. КАК ЗАКРЫТЬ СЕРВЕР
------------------------------------------------------------

   1. Перейдите в окно терминала, где запущен сервер.
   2. Нажмите комбинацию клавиш:
      Ctrl + C
   3. Если появится вопрос "Завершить выполнение пакетного файла? (Y/N)", нажмите:
      Y
      а затем Enter.
   4. Окно можно закрыть.

------------------------------------------------------------
ВАЖНО: Для работы сервера должен быть установлен Node.js.
Проверить установку можно командой: node -v
